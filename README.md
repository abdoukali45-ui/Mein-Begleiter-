# Mein Begleiter – V0.1

Dies ist die erste UI-Prototyp-Version.

Enthalten:
- sehr große, einfache Oberfläche
- Startseite
- Gesprächsseite
- Mikrofon-Schaltfläche als UI-Prototyp
- klare Kennzeichnung, dass der Begleiter eine KI ist

Noch NICHT enthalten:
- echtes Speech-to-Text
- echtes KI-Modell
- Text-to-Speech
- persönliche Memory-Datenbank
- Benutzerkonto
- Familien-Dashboard

## Start
1. Flutter installieren.
2. In diesem Ordner ausführen:
   flutter pub get
   flutter run

Nächster technischer Schritt:
Mikrofon -> Speech-to-Text -> KI-Antwort -> deutsche Sprachausgabe.
